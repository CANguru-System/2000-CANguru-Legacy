# 2000-CANguru-Legacy

**Frühere CANguru-Repositories – Software aus dem Buch, OTA-Versionen,
Bibliotheken, CANguru-Bridge V5, Werkzeuge und Dokumente.**

In diesem Repository sind die früheren CANguru-Repositories zusammengefasst.
Jeder Ordner enthält den unveränderten Inhalt des gleichnamigen früheren
Repositories einschließlich seiner vollständigen Versionsgeschichte.
Die aktuelle Version des CANguru-Systems befindet sich in
[1000-CANguru-Aktuelle-Version](https://github.com/CANguru-System/1000-CANguru-Aktuelle-Version).

*This repository combines the former CANguru repositories. Each folder holds the
unchanged content of the former repository of the same name, including its full
commit history. The current CANguru version lives in
[1000-CANguru-Aktuelle-Version](https://github.com/CANguru-System/1000-CANguru-Aktuelle-Version).*
